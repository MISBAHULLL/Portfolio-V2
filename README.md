## <a name="introduction">🤖 Introduction</a>

A modern, interactive portfolio website built with Next.js 14, featuring stunning 3D elements, smooth animations, and a sleek dark theme. This portfolio showcases my work in **Data Analytics** and **Web Development**, combining technical expertise with creative design.

**Live Demo**: [Coming Soon]

## <a name="tech-stack">⚙️ Tech Stack</a>

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js, React Three Fiber
- **Animations**: Framer Motion, GSAP
- **Physics**: Rapier (for 3D Lanyard)
- **TypeScript**: Full type safety
- **UI Components**: Custom components with React Bits inspiration

## <a name="features">🔋 Features</a>

### ✨ Visual Effects
- **Light Pillar Background** - Ethereal animated WebGL background effect
- **3D Lanyard Badge** - Interactive physics-based ID card with rope simulation
- **Target Cursor** - Custom animated cursor that snaps to interactive elements
- **Hover Animations** - Smooth scale and glow effects on buttons and cards

### 📱 Sections
- **Hero** - Dynamic introduction with Profile Card and 3D Lanyard
- **About (Bento Grid)** - Modern grid layout showcasing skills and background
- **Projects** - Filterable project gallery with categories (Web Dev, Data & ML, Blockchain)
- **Testimonials** - Scrolling experience highlights
- **Experience** - Professional background display
- **Contact** - Easy-to-reach footer with social links

### 🛠️ Technical Features
- **Fully Responsive** - Optimized for all screen sizes
- **Dark Mode** - Premium dark theme throughout
- **Project Filtering** - Filter by category with smooth GSAP animations
- **Pagination** - Browse through projects with animated transitions
- **SEO Optimized** - Meta tags and semantic HTML
- **Performance** - Dynamic imports for 3D components

## <a name="quick-start">🤸 Quick Start</a>

### Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/MISBAHULLL/Portfolio-V2.git
cd Portfolio-V2
```

2. **Install dependencies**
```bash
npm install
# or
pnpm install
```

3. **Run the development server**
```bash
npm run dev
# or
pnpm dev
```

4. **Open in browser**
```
http://localhost:3000
```
